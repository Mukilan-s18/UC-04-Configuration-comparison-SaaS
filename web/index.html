Terms of Service (Draft)

1. Scope of Service: ConfigGuard provides environment configuration validation and comparison services based on the Advantix SaaS specification. All evaluations operate strictly within defined subscription quotas.

2. Tenant Isolation: Data processed under one tenant account is cryptographically and relationally isolated from other tenants. Cross-tenant access is prohibited and enforced at the API layer.

3. Daily Quotas: Usage allowances reset daily at 00:00:00 UTC. Quota deductions occur upon acceptance of unique execution runs. Duplicate requests using identical idempotency keys do not incur additional quota deductions.

4. Draft Status: This document represents a working operational policy drafted for the Advantix SaaS challenge and does not constitute a commercial warranty.

Privacy Policy (Draft)

1. Data Ingestion: Configuration batch entries submitted to ConfigGuard are retained solely for execution evaluation and tenant-scoped history review.

2. Request Fingerprinting: Payloads are hashed using canonical SHA-256 for deterministic idempotency verification. No credentials, tokens, or external identifiers are exposed in public endpoints.

3. Zero External Sharing: Data submitted is processed within isolated database and container environments. No user data is transferred to third-party tracking or advertising networks.

4. Retention and Teardown: Execution records persist according to tenant subscription policy and are permanently removed upon automated infrastructure cleanup.
